06. Discord Bots & Data Processing Architecture

Our community platform operates on servers provided by Discord Inc. (444 De Haro Street, Suite 51, San Francisco, CA 94107, USA). Interactive bots servicing the community are executed locally on a private dedicated home server located in Austria, communicating exclusively over encrypted TLS connections via the official Discord Gateway API.

Inactivity Monitoring (@Member Bot)

Processes public Discord User IDs and message activity timestamps solely to identify inactive members and automate role adjustments under Art. 6(1)(f) GDPR. Data is maintained strictly in volatile runtime structures or memory and is automatically deleted whenever a member leaves the server.

Role Management & Modals (@Role Bot)

Handles role assignments and interactive commands. The /verify system applies a single-attempt captcha challenge to block automated bots[cite: 1]. Cooldown timers, verification failure lockouts (1 hour), and global anti-spam limits (2.5 seconds) exist strictly in RAM and are wiped automatically on bot restart. Verification failure logs and /beta apply modal submissions (name, motivation, rule acceptance) are sent exclusively as text messages into private staff channels on Discord for administrative review[cite: 1].

Age Bracket Assignment (/age via @Role Bot)

To safeguard minors and enforce channel gating, selecting an age bracket is mandatory[cite: 1]. The raw numerical age entered via /age is evaluated ephemerally in RAM, assigns the designated bracket role, and is immediately overwritten and discarded[cite: 1]. No record of the exact numerical value is stored or logged.

Birthday Lookups (@Birthday Bot)

Sharing birth dates in the #birthdays channel is entirely voluntary. The Birthday Bot references a public Google Docs index to return matching query results via /birthday[cite: 1]. Stored dates are synchronized and purged via daily batch maintenance runs at 00:05.
